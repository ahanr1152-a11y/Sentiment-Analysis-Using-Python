# Sentiment-Analysis-Using-Python
Movie Sentiment Analysis using Machine Learning 🎬🤖
A Python-based Sentiment Analysis project that uses the NLTK Movie Reviews dataset and a Multinomial Naive Bayes classifier to predict whether a movie review is Positive or Negative.
🚀 Features
Uses the NLTK Movie Reviews dataset
Text feature extraction using CountVectorizer
Machine Learning model using Multinomial Naive Bayes
Train-test data splitting
Model evaluation with accuracy score and classification report
Custom movie review sentiment prediction
🛠️ Technologies Used
Python
Pandas
NLTK
Scikit-learn
📌 Project Workflow
Dataset → Text Vectorization → Train/Test Split → Model Training → Evaluation → Sentiment Prediction
Short GitHub repo tagline:
🎬 Movie Sentiment Analysis using Python, NLTK, Scikit-learn, CountVectorizer, and Multinomial Naive Bayes.
